Detour — VPN-клиент со встроенным zapret (Windows 10/11, 64 бит)

1. Распакуй папку целиком куда угодно (не запускай прямо из архива).
2. Запусти Detour.exe. Установка не нужна.
3. Скопируй ссылку на подписку своего VPN (https://...) или ключ (vless://, hysteria2:// ...)
   и нажми Ctrl+V в окне программы.
4. Выбери сервер двойным щелчком и нажми «ПОДКЛЮЧИТЬ».
   Режим TUN пускает через VPN весь компьютер, программа попросит права администратора.

Российские сайты идут напрямую, Discord и YouTube — через zapret (сначала через VPN, пока
программа не проверит, что zapret у тебя работает), остальное заблокированное — через VPN.
Правила меняются на странице «Правила».

Важно:
- Не запускай одновременно с другим VPN (Throne, Happ, Hiddify и т.п.): два VPN мешают друг другу.
- Защитник Windows может ругаться на WinDivert (папка bin\zapret). Это драйвер перехвата
  пакетов, на котором работает zapret, а не вирус.
- Внутри страница «Справка» с ответами на частые вопросы.
